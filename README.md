# Скупка: плавающий калькулятор для скупки ресурсов

Android-приложение с иконкой «💎 Скупка». После запуска в углу экрана появляется кружок поверх всех приложений, в том числе поверх игры. Нажатие на кружок открывает панель:

- **Цены**: цена за 1 шт. для жемчуга, рубинов, сапфиров, изумрудов и алмазов. Ресурсы можно переименовать, удалить или добавить свои (например, железо).
- **Трейд**: вписываете, сколько ресурсов вам дают, и сразу видите сумму к выплате (8 шт. по 10 = 80) и общий итог.
- **📋 Объявление**: копирует текст вида «Куплю ресурсы: жемчуг — 10, рубины — 15. Кидайте трейд!», который остаётся вставить в чат игры.

Приложение не вмешивается в игру: оно ничего не нажимает и не читает за вас, это просто калькулятор поверх экрана. Трейды вы принимаете и деньги передаёте сами.

Требования: Android 8.0 и новее.

---

## Как получить APK без программ на компьютере (через GitHub)

1. Зарегистрируйтесь на github.com.
2. Нажмите **New repository**, назовите его, например, `skupka` и нажмите **Create repository**.
3. На странице репозитория нажмите **uploading an existing file** и перетащите **всё содержимое** распакованной папки `skupka` (вместе с папками `app`, `gradle` и `.github`), затем нажмите **Commit changes**.
   - Если папка `.github` не перетащилась (на некоторых системах скрытые папки не видны), создайте файл вручную: **Add file → Create new file**, имя `.github/workflows/build.yml`, а содержимое скопируйте из одноимённого файла в архиве.
4. Откройте вкладку **Actions**. Сборка «Собрать APK» запустится сама и займёт 3–5 минут. Если она не запустилась, выберите её слева и нажмите **Run workflow**.
5. Когда появится зелёная галочка, откройте сборку и внизу в разделе **Artifacts** скачайте `Skupka-apk`. Внутри архива лежит `Skupka.apk`.

## Как собрать в Android Studio

1. Установите Android Studio (developer.android.com/studio).
2. Нажмите **File → Open** и выберите папку `skupka`. Подождите, пока Studio всё скачает.
3. Выберите **Build → Build App Bundle(s) / APK(s) → Build APK(s)**.
4. Готовый файл появится в `app/build/outputs/apk/debug/app-debug.apk`.

## Установка на телефон

1. Скопируйте APK на телефон и откройте его. Разрешите установку из этого источника, если телефон спросит.
2. Запустите «Скупка» и нажмите **Разрешить показ поверх других приложений**, затем включите переключатель.
3. Нажмите **Запустить кружок** и откройте игру.

На **Xiaomi / Redmi / POCO** дополнительно: Настройки → Приложения → Скупка → Другие разрешения → «Отображать всплывающие окна, когда запущено в фоновом режиме».

## Раздача через сайт

APK можно выложить на свой сайт или в облако и дать ссылку на скачивание. Android при установке предупредит, что приложение не из Google Play. Для файла, скачанного не из магазина, это нормально.
